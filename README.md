# 東京冬旅 1/30 – 2/3

以上野為基地的五天東京冬季行程表。單一檔案靜態網頁（`index.html`），無建置步驟、無相依套件。

**線上版本**：https://chientaichan.github.io/tokyo-winter-trip/

內容包含：

- 五天逐時段行程（抵達日合羽橋買鍋、東京車站角落生物、新大久保、原宿運動潮牌、豐洲市場、teamLab Planets）
- 店家清單：日韓潮牌與化妝品、運動品牌、角落生物專賣店、HARBS、輕珠寶
- 預約時間表（各店開放訂位的日期換算）
- 交通路線、超市採買與免稅新制提醒

支援淺色／深色模式與手機版面。

## 個人資訊

這是公開版本，已移除住宿名稱與地址、班機編號、同行友人與返家路線等個人資訊，保留的都是公開店家與大眾運輸資訊。頁面另外設了 `noindex`，不會被搜尋引擎收錄。

## 本機預覽

用瀏覽器直接開 `index.html`，或：

```bash
npx serve .
```
